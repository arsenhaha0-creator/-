# Карта жизни: приложение для iPhone (вне App Store)

Это проект приложения с уведомлениями. Mac не нужен: сборку делает бесплатный сервер GitHub, а установку на iPhone делает программа Sideloadly (Windows или Mac) или AltStore.

## 1. Собрать приложение (файл .ipa)
1. Создайте аккаунт на github.com и новый репозиторий (private подойдёт).
2. Загрузите в него все файлы из этого архива: Add file → Upload files. Папка .github может не загрузиться из-за скрытого имени. Тогда нажмите Add file → Create new file, в поле имени введите `.github/workflows/build-ios.yml` и вставьте содержимое файла `workflow-build-ios.yml` из архива.
3. Откройте вкладку Actions → Build iOS IPA → Run workflow. Сборка занимает 5–10 минут.
4. Когда появится зелёная галочка, откройте запуск и скачайте внизу артефакт `KartaZhizni-ipa`. Внутри архива лежит `KartaZhizni.ipa`.

## 2. Установить на iPhone
1. Установите Sideloadly (sideloadly.io) на компьютер и подключите iPhone кабелем.
2. Перетащите `KartaZhizni.ipa` в Sideloadly, введите свой Apple ID и нажмите Start.
3. На iPhone включите режим разработчика: Настройки → Конфиденциальность и безопасность → Режим разработчика. Затем доверьте профиль: Настройки → Основные → VPN и управление устройством.
4. Откройте приложение и нажмите «Включить уведомления» в блоке «Напоминания».

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить через Sideloadly (данные при этом могут сброситься). Платная подписка Apple Developer (99 долларов в год) продлевает срок до года.

## Где что менять
Весь интерфейс лежит в `www/index.html`. Стартовые напоминания: поиск `rem:[` в этом файле.
